# Slotline: Appointment Booking & Staff Scheduling

Role: Java & Full-Stack Developer | PostgreSQL, TypeScript, Docker

Appointment booking MVP with a Java 21 API, PostgreSQL storage and a TypeScript web interface. Guests book, reschedule or cancel through private links; staff manage weekly hours, date exceptions and time blocks. Database exclusion constraints protect occupied intervals, and atomic rescheduling preserves the original reservation on conflicts. Includes time-zone-aware availability, retry-safe requests, audit history, calendar exports and Docker setup. Personal portfolio project with fictional catalogue data.
